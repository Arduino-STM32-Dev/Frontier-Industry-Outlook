## 报告讲了什么

- **技术坐标系（L0–L5）**：把"让电机按设定值精确转动"拆成六层，逐层看市场形态与竞争焦点。
- **已实现领域**：家电变频、汽车电驱、工业机器人与伺服、无人机与电动工具、医疗中低端、创客教育市场——按"批量出货 / 有强制标准 / 维护生态完备"三条硬标准判定。
- **正在探索领域**：人形机器人关节与灵巧手、航空电动化、轴向磁通电机、无稀土电机、宽禁带驱动、具身智能 VLA、外骨骼。
- **边缘计算专题**：五条硬理由（时延、带宽成本、隐私合规、断网自治、数据价值密度）、市场规模信号、硬件阶梯、软件栈、端侧临界点、分场景应用前景、五条工程红线与四类风险。
- **趋势总结**：七条趋势、三个最值得盯的指标，以及一条结构性判断。
